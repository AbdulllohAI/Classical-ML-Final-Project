## Overview

This project implements three complete, independent machine learning pipelines — one per dataset — each covering the full classical ML workflow:

1. **Exploratory Data Analysis** — shape, missing values, duplicates, target balance, distributions, outliers, correlations, bivariate relationships
2. **Data Preprocessing** — cleaning, encoding, and justified handling of missing/duplicate data
3. **Feature Engineering** — two hand-crafted features per dataset, grounded in domain reasoning
4. **Feature Importance** — Random Forest–based ranking with interpretation
5. **Model Training** — XGBoost, LightGBM, and CatBoost, evaluated on Accuracy, Precision, Recall, F1, and ROC-AUC
6. **Hyperparameter Tuning** — `RandomizedSearchCV` across 5 parameters per model
7. **Model Comparison & Final Analysis** — best model per dataset, speed trade-offs, and a production recommendation

Every notebook is fully executed and reproducible — all outputs, tables, and charts you see were generated by re-running the code, not hand-written.

```
EDA → Data Cleaning → Feature Engineering → Feature Importance → Model Training → Hyperparameter Tuning → Model Comparison
```

## Key Insights

- All three targets are **imbalanced**, so F1 and ROC-AUC — not raw accuracy — drove model selection.
- **Behavioral/transactional features** (e.g. `Total_Trans_Ct` in Dataset 1, `IsActiveMember` in Dataset 3) are consistently stronger churn signals than demographic ones.
- Hand-engineered features (2 per dataset) ranked in the **top 10** feature importances in every dataset — evidence that domain-informed feature engineering pays off.
- Hyperparameter tuning yielded modest gains (F1 typically +0.01–0.03) — default gradient-boosting settings were already strong baselines.
- XGBoost, LightGBM, and CatBoost perform within a narrow margin of each other on every dataset; the practical tie-breaker is usually training/inference speed and native categorical support.

## Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/Classical-ML-Final-Project.git
cd Classical-ML-Final-Project

# 2. Create and activate a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Open any dataset's notebook
cd Dataset-1                     # or Dataset-2, Dataset-3
jupyter notebook notebook.ipynb
```

Each notebook reads its dataset from a relative `data/` path and writes charts to a relative `images/` path — always run it from **inside** its own `Dataset-X/` folder.

To re-run a notebook end-to-end from the command line:

```bash
jupyter nbconvert --to notebook --execute --inplace notebook.ipynb
```
